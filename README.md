# LOCALPLAN v0.20 — 情境教學、素材庫與第一人稱

以 `index.html` 開啟；網頁部署使用相對路徑，不需要 Node 或 CDN。

- 2D／2.5D：滾輪以游標為中心縮放，拖曳空白處、中鍵、空白鍵＋拖曳或平移工具；點擊倍率適合畫面。左鍵拖動設備不受平移影響。
- 人員配置：從各站加入員工，指定取料站與交付站、各站停留秒數；員工起點可回到畫布移動。專案 JSON 保留員工配置。
- 開始運作：沿通道移動、取料、攜帶貨物、交付、返回取料。暫停、繼續、停止及 0.5–40 倍速度；切換 2D／2.5D／3D 時保持模擬時間及人物位置。
- 咖啡廳另外生成顧客、點餐、取餐、入座及離店。各角色有簡化避讓、等候、阻滯計算。
- 運作資訊可展開查看個別員工路程及搬運次數；2D 可顯示活動路線與阻滯熱區。

目前為簡化離散人物模型：員工搬運為獨立重複任務，尚無物料庫存、前後工序同步、完整排隊服務或人體負荷校準；加速倍率受裝置效能限制。保留原 LICENSE 與資源包。此公開網站不含論文。

- 節點動線：選擇物流關係，在通道插入、拖曳、刪除必經點；手動路徑納入路程及人物尋路，原方案、復原及 JSON 保留節點。
- 2D／2.5D／3D 各自保存縮放與平移；拖曳設備時避免檢視面板改變畫布尺寸造成位移。

## v0.19

- 上方「預設情境／教學」：六個完整案例（工廠初次搬運、多人分工、繞路改善；咖啡廳平日、尖峰、淨空挑戰）。可直接載入或進入任務模式，依畫布操作檢查目標，完成後答題。各案例自帶人員與模擬參數。
- 左側素材庫可收合、單欄或展開為多欄目錄，展開寬度可由 25% 至 60% 拖動或鍵盤調整；支援搜尋與分類。
- 咖啡廳桌椅對向排列，入口方向、冰箱、通道與前窗修正；前窗底部標高 0.90 m，下方有同寬矮牆。這是預設案例的示範尺寸，可在解鎖後調整。
- 第一人稱 WASD／方向鍵長按連續移動（1.35 m/s），對角移動正規化，碰撞時可沿設備滑行；拖曳轉頭在動畫幀更新。重複空間分析快取；軟體渲染第一人稱降低內部解析度。
- 原本的 CAD、動線節點、方案比較與原始模型資產保留；既有已儲存的自訂場地不會自動覆寫。
- 模擬仍是簡化模型，咖啡廳人物在桌旁等候，不是完整坐姿動畫；示範參數未經現場校準。

## v0.20 — 分區式咖啡廳、3D 直接編輯

- 依參考平面配置重建 18 × 13 m 咖啡廳（尺寸為示範假設，非原圖測量）：廁所、洗手間、儲藏空間、廚房、展示區、櫃台、咖啡工作區、烘豆區、用餐區。34 個座位，90 個配置元件；原有六個教學情境保留，三個咖啡廳情境套用新平面。
- 前窗四扇連續窗組：底部 Z=1.15 m、窗高 1.20 m、頂部 Z=2.35 m，外牆高 2.70 m。窗下牆、窗上牆、窗框為獨立元件。透明玻璃以開口示意；保留原 BBMODEL 素材不變。解鎖可調整元件。3D / 2.5D 的「牆體：剖視」僅隱藏近側外牆，分析與第一人稱碰撞仍採完整牆體。
- 3D 自由視角：左鍵拖曳設備沿水平面移動，選取後拖曳 Z 控制點調整高度（0.05 m 吸附），或選「Z 高度」直接拖曳物件。空白處旋轉；中鍵、右鍵或 Shift 拖曳平移相機。固定設備需解鎖；模擬進行中需先停止。復原、原有 JSON 坐標及 2D/2.5D 共用同一份配置。
- CAD 面板使用 X、Y 為水平坐標，Z 為離地高度；為相容舊 JSON，內部維持 x、z、baseY 欄位。
- 新增圓桌、圓凳、長桌、靠窗桌、馬桶、洗手台、烘豆機基本方塊資產；一般與尖峰配置經幾何檢查均無重疊、三條預設物流皆可達。顧客模擬使用三組桌位目的地，並未實作全部 34 個座位的容量分配或真實坐姿。尖峰案例仍可形成排隊。
- 測試：Chromium（內嵌原始碼、CPU 3D 備援）實際滑鼠拖曳 CNC 水平位置及 Z 控制點；2D、2.5D、3D 切換、三個咖啡廳情境、正常營運及尖峰搬運、淨空挑戰皆有測試。硬體 WebGL 效能未驗證。

## v0.21 手機介面

手機窄螢幕／觸控裝置自動使用手機版，桌面版維持原有操作。網址加 `?mobile=1` 可在電腦開啟獨立的窄版手機預覽（非真機模擬）。底部切換「瀏覽／編輯」：瀏覽單指平移（3D 旋轉）、點選設備；編輯拖曳設備、動線節點與 3D 高度；雙指縮放，3D 雙指平移與視距調整。素材、屬性與視角按需展開；第一人稱左下方向鍵可長按，畫布拖曳轉頭。操作面板保留模擬及情境教學。
